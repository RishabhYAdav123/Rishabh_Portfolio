# Rishabh Yadav Portfolio

Premium personal portfolio for an AI/ML Engineer and Full Stack Developer, built with Next.js 15, React, TypeScript, Tailwind CSS, Framer Motion, ShadCN-style components, and Lucide Icons.

## Live Demo

[View Portfolio](https://rishabh-portfolio-ebon.vercel.app)

## Features

- Futuristic dark UI with glassmorphism, animated particles, cursor glow, scroll progress, and smooth section reveals.
- Hero with animated role typing, resume download, social links, and profile visual.
- About, education, skills, statistics, tech stack, featured projects, experience, achievements, and contact sections.
- Dynamic GitHub integration for `RishabhYAdav123`.
- Automatic repository sorting, tech detection, category filtering, stars/forks, README summary extraction, and live demo detection.
- Responsive layout for mobile, tablet, and desktop.
- SEO metadata, accessible controls, theme toggle, and production-ready structure.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```

## Personalization

Main content lives in:

- `src/components/portfolio/data.ts`
- `src/components/portfolio/portfolio.tsx`
- `src/components/portfolio/github.ts`

The resume download is served from `public/resume.pdf`.
